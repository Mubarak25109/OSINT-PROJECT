# LinkGuard OSINT — Windows Edition

This is a normal Windows desktop window application. It does not require Kali Linux.

## Run it

1. Extract `LinkGuard_Windows.zip` to a folder.
2. If Python 3 is not installed, install it from https://www.python.org/downloads/
   and select **Add python.exe to PATH** during setup.
3. Double-click `Start_LinkGuard.bat`.

The app uses Python's standard library and Tkinter. No pip packages are needed.

## Features

- URL validation and domain extraction
- DNS / IP lookup
- HTTPS and website availability check
- HTTP status and response-time measurement
- Public robots.txt status and preview
- TLS certificate verification
- Copyable text report

This is a passive educational checker. It does not prove a website is safe.
Only inspect websites you are authorized to check.
